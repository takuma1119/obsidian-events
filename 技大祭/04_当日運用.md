# 当日運用

第44回: 準備日9/12(金) → 1日目9/13(土) → 2日目9/14(日) → 片付け日9/15(月)

## 団体ごとの流れ（台帳の列と対応）
```
準備日: 封筒受取 → 封筒返却 → 本部確認
1日目 : 封筒受取 → 農ポリ・耐熱板受取 → 開店チェック受付 → 完了 → 本部確認
        → 検体提出 → 閉店チェック受付 → 完了 → 本部確認
2日目 : 封筒受取 → 開店チェック → 検体提出 → 閉店チェック
片付け: 物品返却 → 返却完了
```
「封筒」には当日資料（チェックリスト、リストバンド、営業許可証など）が入る。

## 日程の目安（第3回資料より。表が崩れて読みにくいので要確認）
- 開店準備7:00台、開店チェック8:15〜
- 準備日: 物品貸出（屋外団体）、会場設営、閉店チェック16〜17時
- 9:00〜10:00は講義棟の貸出物品のみ貸出可
- 運営本部: 電気1号棟1階
- 物品の貸出場所: AL3、体育館、201・205講義室

## 開店チェック・閉店チェック
- 営業許可は**開店チェックに通った団体**に出る。調理場も許可後から使える
- マニュアルは別資料（Driveの「開閉店チェックマニュアル（改訂版）」）→ [[08_未読資料とTODO]]
- 総務局員用の「当日の確認事項マニュアル」を作りたいという案あり（天幕に物を貼っていないか／バンダナ・エプロン・手袋の着用／食事をしていないか など）

## テントチェック
- 準備日にも行う（団体にも立ち会ってもらう）
- 冷蔵庫がテントに触れて問題になった → テント内に置くものの**高さ制限**、準備日に持ってきてもらう
- 「脚をたたんだ後、テントに膨らみはないか」が軽視されがち → 禁止事項だけでなく**理由**を書く
- チェック項目は物品局に作ってもらう案、指揮は物品から1人

## 物品の管理
- 台車は**番号を付けて**貸し、貸出時に番号を控える
- 耐熱板は管理表を事前に作る（数と貸出先）。値段が高いので重要性を周知
- 貸出物品表は3枚は多い。1枚にまとめる案
- 机保護の担当は早めに決める（今年は直前に変わった）。遅くとも第3回説明会までに
- ラミ（貼り紙）は封筒に入れず、本部で管理。開店チェックで渡して貼ってもらう

## 衛生
- 食品販売ではマスク・バンダナ・エプロン・手袋が必要。守られていない団体があった
- 説明会資料にマスク着用の記載がなかった → 追記する

## 片付け日
- 返却の流れが煩雑。団体がこまめに椅子や机を運ぶと、どの団体のものか分からない → **まとめて運んでもらう**
- 来なくていい屋内団体が来てしまった → 資料と口頭（2日目の閉店チェックなど）で周知
