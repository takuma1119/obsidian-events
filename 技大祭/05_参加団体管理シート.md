# 参加団体管理シート（台帳）

第44回は「44th_参加団体管理」というGoogleスプレッドシートで管理。約60団体、1団体1行。
**この台帳の列の並びが、参加団体担当の仕事の順番そのもの。**

> 個人情報（代表者・副代表者の氏名、電話、メール）が入っているので、中身はこのVaultに写さない。

## 列の構成
| ブロック | 列 | 何のために |
|---|---|---|
| ① 代表者・副代表者 | 氏名、電話、メール（リンクあり/なしの2系統） | 連絡先。副代表も必ず取る |
| ② 団体情報 | 団体種別（国内団体など）、参加形式、配置種別（屋内/屋外）、配置、火気使用、耐熱板の枚数想定 | 当日の準備物と配置の元データ |
| ③ 説明会出欠 | 第1〜4回の出席日、出店資格 | 出ていない団体は別日・メール対応。出店資格は「出店可」など |
| ④ 準備日 | 封筒受取、封筒返却、本部確認 | 準備日のチェック |
| ⑤ 1日目 | 封筒、農ポリ、耐熱板、開店チェック、検体提出、閉店チェック、本部確認 | 当日1日目 |
| ⑥ 2日目 | 封筒、開店チェック、検体提出、閉店チェック、本部確認 | 当日2日目 |
| 最後 | 返却完了 | 片付け日 |

- チェック欄はTRUE/FALSEのチェックボックス。列ごとの集計（何団体が完了したか）を上の行に置く
- 前の版には、45L・90L保護枚数（机保護の袋）の列があった。後の版で耐熱板中心に整理された
- 古いシートは「削除予定」として残してある

## 作り方の考え方
- 台帳は**早めに作り、更新を1か所に集める**。メール等で更新された情報は、すぐに反映する
- 台帳のデータから、封筒の表紙・従業員チェックリスト・従業員リストバンドの表紙をスクリプト（GAS）で自動作成した（去年より手間が減った）
- 模擬店平面図は管理システムGM3で団体ごとに開いて印刷。1日がかり。団体名が入らず分かりにくい → 情報局に改善を依頼（優先度は低）
