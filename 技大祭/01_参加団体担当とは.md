# 参加団体担当とは

総務局の中の**参加団体部門**。技大祭に出る団体（模擬店、展示、研究室公開、ステージなど）の窓口になり、申し込みから片付けまでを管理する。

## 担当する団体の種類
- 食品販売団体（模擬店）
- 物品販売団体
- 展示・体験団体
- 研究室公開
- ステージ団体（※ステージの打ち合わせ・管理は**企画局**が主担当。ただし団体からの連絡は総務に来るので情報共有は必須）

## 仕事の柱
1. **募集と選考** — 参加募集メール、抽選（ある場合）、出店資格の確認
2. **説明会** — 第1〜4回の参加団体説明会の資料作成と実施 → [[03_参加団体説明会]]
3. **申請・提出物の管理** — 火気使用申請、検便、模擬店平面図、各種フォーム
4. **連絡窓口** — メールとLINEオープンチャットでの対応
5. **当日運用** — 封筒の受け渡し、開店・閉店チェック、テントチェック、物品貸出 → [[04_当日運用]]
6. **台帳管理** — 全団体の状況を1つのシートで追う → [[05_参加団体管理シート]]
7. **終了後** — 反省会、アンケート、売上額報告、引き継ぎ → [[06_第44回の反省と引き継ぎ]]

## 連携する局
| 局 | 主な関係 |
|---|---|
| 渉外 | 地域・他大学 |
| 企画 | ステージ、企画。窓口は副局長が良いという意見あり |
| 制作 | ポスター、のぼり |
| 情報 | 管理システム「GM3」（模擬店平面図などの入力） |
| 財務 | 予算、非営利団体の補助 |
| 物品 | 貸出物品、テントチェックの項目作成 |

特に渉外・企画とは、ぶつからないよう早めに話し合う。

## 連絡の使い分け（第44回）
- 全体連絡・複数団体に関わる質問 → LINEオープンチャット
- 個別連絡・個別の質問 → メール
- 重要連絡 → 両方
