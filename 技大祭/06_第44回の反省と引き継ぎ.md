# 第44回の反省と引き継ぎ

元資料: 第44回 総務局参加団体MT 第20回（9/26、反省会）。「44thから45thに向けて直したいこと、変えたいこと」を全員で出した。

## 決定事項
- 参加団体資料のヘッダーの曜日を消す。書式と表記を統一。テーマカラーを変える（統一はする）
- 資料は他の部門と**合同で作る**
- メール対応とオープンチャット対応は**みんなで**
- ポスターは早めに（制作、企画、その後に支援課へ）
- **団体受付期間外の申請は認めない**（曲げないが、親身に）
- ラミは封筒に入れず、本部で管理
- 台車は番号で管理

## 主な課題と対策
| 課題 | 対策案 |
|---|---|
| 部門長のタスクが多い | 4年生に副部門長的なポストを作る。2人1組（4年＋3年または修士1年＋3年）で組ませる |
| 連絡対応の負担 | オープンチャット係（連絡係）を作る。急ぎは経験者、想定内は3年生。最終送信は部門長＋係。Slackに添削チャンネル |
| 抽選がうやむやになった | 募集メールに抽選があることを明記し、抽選方法を早めに決める |
| 営業許可証を勝手に貼る団体 | 営業許可証を封筒に入れない。臨時営業許可証の良い点を第1回で説明 |
| リストバンドの量 | 10,000本ではなく3,000本程度が適量。2年に1回の発注にして引き継ぐ |
| シュレッダーが古い | 個人情報の扱いの面から必須、と予算でアピール |
| 印刷に時間がかかる | 早く作れるものは早めに印刷。大量印刷はbrotherのプリンタを使う |
| 参加団体の受付が分かりにくい | 物品管理との窓口を分け、ラミやAボードで分かりやすく。混雑時は窓口を増やす |
| 動画の手順書は厳しい | 画像の手順書にする（テント設営など） |

## 持ち越し事項（次の代で検討）
- Q&Aの作成（休憩所、飲食可能な場所）
- 第1回に出店例を見せる
- 事前アンケートは第1回だけでよいか
- オープンチャットを原則にしたいが、入りたくない団体への対応（個別メールになりそう）
- 説明会の時間や説明順を見直す
- 前日に開店チェックの内容をメールで知らせる
- 巡回中だと分かるバンドなどで目立たせる
- レシーバー（電話ではない連絡手段）がほしい
- 総務局員用の当日マニュアル
- 準備日・当日・片付け日の開始時間は、部門員と相談後、局長と相談

## この反省から学べること
- 参加団体には**優しくある必要はないが、親身ではあるべき**（ルールは曲げない）
- チェックリストには**理由**を書くと守ってもらいやすい
- 同じ作業を毎年やるので、**自動化できるところは早めに**（台帳→封筒の表紙など）
