# 技大祭から引き継ぐこと

UNI祭の募集要項を読んだうえで、技大祭の前例のうち使えるものを選んだ。

| 技大祭で分かったこと | UNI祭での使い方 | 参照 |
|---|---|---|
| 台帳の列の並び = 仕事の順番 | [[04_参加団体管理シート案]] に反映 | [[../05_参加団体管理シート]] |
| 受付期間外の申請は認めない（曲げないが親身に） | 10/31の締め切りを守る。キャンセル期限も同日 | [[../06_第44回の反省と引き継ぎ]] |
| 抽選がうやむやになった | 「抽選になる場合がある」と募集要項に書いてあるので、**方法を先に決める** | 同上 |
| チェックリストには理由を書く | 当日のルールに「なぜ」を一言添える | 同上 |
| 火気の申請と耐熱板 | UNI祭は屋内。火気の申告を申込フォームで取り、必要なら耐熱板の貸出を検討 | [[../03_参加団体説明会]] |
| 調理場と検便 | UNI祭では調理場がない。食材の仕込みは営業許可のある施設。検便の要否は要確認 | 同上 |
| 開店・閉店チェック | 搬入の受付チェック、営業開始前の確認、撤収の確認に簡略化できる | [[../04_当日運用]] |
| 連絡の使い分け（全体はグループ、個別はメール） | 出店担当宛てのメールに共通のグループアドレスをccに入れる運用が既にある | [[../01_参加団体担当とは]] |
| 台車などの貸出物品は番号で管理 | 机・椅子・テントなどを貸す場合に、数と貸出先を控える | [[../04_当日運用]] |

## 技大祭とUNI祭の違い
| | 技大祭 | UNI祭 |
|---|---|---|
| 規模 | 約60団体、2日間 | 1日。出展区分が3つ |
| 会場 | 大学のキャンパス（屋外が中心） | アオーレ長岡（屋内、全天候型） |
| 営業許可 | 団体ごとに衛生ルール、実行委員会が検便・調理場を管理 | 飲食は実行委員会名義の臨時営業許可。書類を集めて申請 |
| 準備期間 | 数か月、説明会4回 | 約7週間 |
| 食品衛生責任者 | | 実行委員会の代表者 |

## 使えない（かもしれない）もの
- 4回の説明会、検便の回収、調理場の運用は、そのままでは重すぎる
- 説明会は1回か資料の配布で済ませられるか確認する
