**精度の注意:** 読み取りの途中で要約が圧縮されたため、企画演出・実行委員企画・DJ・太鼓は薄い。ライブとステージは比較的しっかり。画像・添付・リンク先は未読。数字は原文で再確認すること。

## 全体像
- 会場はアオーレ長岡。メインステージ、DJステージ（サブステージ、島型配置案）、ミライエでのバンドライブ（UNISONLIVE）の3系統
- 音響・照明はMIC合同会社、ステージ造作・装飾はデリカ
- 制約: 騒音65dB、電源は1回路20A（アオーレは1系統1,500W）、備品貸出の申請は1か月前

## 1. ステージ（uni_ステージ）
- ステージUnitの総合チャンネル。タイムテーブル、出演団体、ファッションショー、装飾、DJブース、MIC/デリカ調整、定例MT（20時〜）
- 決定: ダンスの応募は学校単位でなく部・サークル内のグループ単位で可 / ファッションショーの出演者はメイク等のサポート役を控室に同行してよい / 地元高校の吹奏楽部は辞退
- 課題: タイムテーブル確定、オープニング/クロージング案、転換時間の使い方（じゃんけん大会など）、司会台本、ステージ装飾案
- 装飾の発注（MIC・デリカ）は、10/21の装飾MTGでの合意待ち。ステージ統括が多忙で、代行体制は未定
- 技大吹部とTECの返信を、募集期限が近いので早めに返すよう催促あり
- 未読: キックオフ日程、筋肉コンテスト、当日アナウンスのタイムテーブルなどのスレッド

## 2. DJステージ（uni_ステージ-djステージ）
- DJブースはサブステージとして整備予定。位置は未確定（島型の案）
- 組織図上はブースUnit所属だが、ステージUnitと一緒に進める方向。音響側の人にDJブース部分を頼んでよいか、代表が確認する流れ
- 未決: 位置、長机・椅子・テントの数、電源合計、ブースUnitとステージUnitの責任分界
- 資料: DJハドル議事録3件、DJステージ打合せ（10/3）のcanvas

## 3. 太鼓演奏（uni_ステージ-太鼓演奏）
- 参加通知と調整連絡1件のみ。出演時間・人数・搬入方法の記載なし

## 4. ライブ（uni_ライブ / ミライエのバンドライブ）
- 想定タイムテーブル: 12:15開場 → 12:45〜12:50開演・オープニング → 最大9バンド（演奏15分＋転換15分）12:50〜17:05 → 17:05〜17:20クロージング → 17:30完全終了
- 15分枠の理由: 高校・高専の3年生は引退済みで20分超は負担、リハなしのため転換時に簡易音出しをしたい
- 「1曲だけ出たい」1・2年生の参加機会との兼ね合いで、定例で再協議。9組集まらない場合は1組の時間を延ばす案
- 応募状況: 当初0件 → 声かけ強化 → 6件前後（1曲のみの出演が多い）
- 応募締切は11/10に延長（募集要項とフォームの日付変更を依頼済み）
- ミライエのセッティング/内装図: 最終的には業者が図面化。意図を伝える素案と会場図は、ライブ担当が作成（了承済み）
- 未決: 最終出演数、演奏・転換時間、広報
