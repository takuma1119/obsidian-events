# 参加団体管理シート案

技大祭の台帳（[[../05_参加団体管理シート]]）と、UNI祭の募集要項から考えた列の案。**自分のスプレッドシートは、まだ作っていない（Driveには書き込まない方針）**。作る前にこの案を見直す。

> 氏名・電話・メールはこのVaultに書かない。シート側で管理する。

## 方針
- 出展区分が3つ（アリーナ／飲食／キッチンカー）あり、必要な書類が違う → **1シートに区分の列を作り、区分ごとに必要な列を絞る**
- 「どこまで進んだか」が一目で分かるよう、状態の列を左側に置く
- 通知・提出・当日の順に列を並べる（技大祭の「列の並び = 仕事の順番」と同じ考え方）

## 列の案
| ブロック | 列 | メモ |
|---|---|---|
| 基本 | 団体名、区分（アリーナ/飲食/キッチンカー/ステージ）、学生団体か一般か、所属 | 出店料が変わる（無料／¥1,000／¥3,000） |
| 連絡 | 代表者、連絡先、メール | 個人情報なのでシート側だけ |
| 申込 | 申込日、申込内容（企画、希望ブース数）、電源W、火気の有無、貸出希望物品と数量 | 申込フォームの回答 |
| 選考 | 状態（申込／確定／抽選待ち／辞退）、通知日 | 飲食は11/3、アリーナは11/7が期限 |
| 出店料 | 金額、受領の状況 | 一般団体のみ |
| 飲食の書類 | 調理計画、ブース平面図、食材の購入場所、従業員名簿、衛生管理の担当者 | 期限11/5 |
| キッチンカー | 営業許可証の写し、車両寸法、火気 | |
| 配置 | ブース番号、場所、電源の割り当て | 実行委員会が割り当てる |
| 搬入 | 搬入日時の割り振り、車の台数 | 12/5か12/6 |
| 説明会 | 出欠（回ごと） | 欠席は別日・メール対応 |
| 当日 | 搬入受付、開店チェック、閉店チェック、撤収・原状復帰 | |
| 備考 | 注意点（アレルギー表示、酒類、過去の問題など） | |

## 集計しておくと便利なもの
- 区分ごとの申込数と確定数（募集数を超えたか）
- 電源の合計W、火気を使う団体の数
- 貸出物品の合計（机、椅子、長机、テント、展示パネル）
- 飲食の書類の提出状況（11/5に向けて）

## 技大祭からの学び
- 台帳は早めに作り、更新を1か所に集める
- メールなどで更新された情報は、すぐに台帳へ
- 受付期間外の申請は認めない（締め切りを最初に宣言する）
