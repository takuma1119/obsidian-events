# 技大祭から引き継ぐこと

UNI祭の規模・形式が分からないので、**使えそうなものの候補**として置く。要らなければ捨てる。

| 技大祭で分かったこと | UNI祭での使い方 | 参照 |
|---|---|---|
| 台帳の列の並び = 仕事の順番 | 団体ごとに1行。連絡先、参加形式、説明会の出欠、当日チェックの列を作る | [[../05_参加団体管理シート]] |
| 連絡の使い分け（全体はグループ、個別はメール、重要は両方） | 連絡手段を最初に決める | [[../01_参加団体担当とは]] |
| 受付期間外の申請は認めない（曲げないが親身に） | 締め切りを最初に宣言する | [[../06_第44回の反省と引き継ぎ]] |
| 抽選がうやむやになった | 募集時に抽選の有無と方法を明記 | 同上 |
| チェックリストには理由を書く | 当日のルールの紙に「なぜ必要か」を一言添える | 同上 |
| 火気・検便・調理場のルール | 食品販売がある場合だけ参考にする | [[../03_参加団体説明会]] |
| 当日の開店・閉店チェック、封筒 | 規模が小さければ簡略化（チェック表1枚など） | [[../04_当日運用]] |
| 台車・耐熱板などの貸出物品は番号で管理 | 物品の貸出があれば同様に | 同上 |

## 違いそうなところ（要確認）
- 規模: 技大祭は約60団体、2日間。UNI祭は1日
- 準備日・片付け日の有無
- 食品販売の有無
