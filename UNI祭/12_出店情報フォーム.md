# 出店情報フォーム（出店が決まった団体向け）

申込のあとに、当日の運営・会場設営・保健所／消防署への届出に使う情報を集めるフォーム。アリーナ出展・飲食店・キッチンカーの3区分を1つのフォームで受け、区分ごとにセクションを分岐させる。
関連: [[13_申込状況と管理シート_1104]] / [[03_出展区分と募集要項]] / [[02_12月6日までのスケジュール]]

## 基本
- 回答期限: **11/6(金)**（書類の締切も同じ日）
- 作り方: 「[検討]フォーム質問項目」タブをもとに、Apps Scriptで骨組みを作り、そのあと手で直した
- フォームの持ち主: 個人のドライブ（組織のアカウントでは「ファイルのアップロード」が使えなかったため移した）
- ファイルのアップロードがあるので、回答者はGoogleログインが必要
- 構成: 基本情報 → 出店区分で分岐（搬入出 → 車両 → 電気 → 借用物品・床 → 火気 → メニュー・提出書類） → HP・SNS掲載 → 同意とご質問
- 送付: 出店者へのメールは全団体共通の文面。宛名は「出店者各位」、BCCで一括送信（To は info@unifes.org）

## 決定ログ
| 論点 | 結論 | 理由・メモ |
|---|---|---|
| 出店者ID | 使わない | 団体名・店舗名で照合。「申込時と同じ表記で」と案内 |
| 机 | 長机のみ（W1,800×D450×H700） | 申込時は「机」も貸せると案内していたが、貸せなくなった |
| 展示パネル | 1団体2枚まで（W1,200×H2,100） | 希望が多く数が足りない。3枚以上は「その他」に枚数と理由 |
| 電力 | 1出店1,500Wまで。フォームの検証で超えられないようにした | 電工ドラムを複数ブースで共有する。超過時の理由欄は削除 |
| 発電機 | 不可 | 燃料の選択肢から「ガソリン（発電機用）」も削除 |
| 飲食の区画 | 1団体1区画（2,500×2,500、テント1張） | 2区画以上の希望は最後の「質問・要望」に書いてもらう |
| 飲食の保健所書類 | Wordのテンプレート1つ（調理計画・平面図・従業員名簿・食材の購入場所）→ PDF 1ファイルで提出 | 臨時営業許可は実行委員会の名義で申請する |
| キッチンカーの書類 | 食品営業許可証の写し（PDF） | 自分の許可で出店する |
| 火気 | 裸火・危険物品の有無を聞き、ありなら消防署への申請用の項目（火元責任者、器具、燃料、時間帯など）を聞く | プロパンは飲食のみ「アオーレの備え付けを使用」 |
| 出店料 | 学生団体は無料、一般団体3,000円（飲食）。当日、案内所で現金 | 選択式（ラジオボタン）で区分も兼ねる |
| 同意 | 「募集要項の内容をすべて読み、理解したうえで同意します」 | 「出店者向け注意事項」という資料は存在しなかった |
| 確認メッセージ | 受付済み＋不備があれば連絡＋変更は速やかに連絡 | |

## 未解決
- [ ] 募集要項の提出期限（9章）が **11/5(木)** のまま。フォームは11/6(金)
- [ ] 前日搬入の時間: フォームは 12/5 14:00〜18:00、募集要項は 15:00〜20:00
- [ ] アリーナの一般団体の出店料: 出店者管理シートは「1,000円」、募集要項は「物品販売は無料」
- [ ] 電工ドラム共有で、全体の電力が足りるか（会場・物品担当に確認）
- [ ] テントを持ち込む団体の扱い（3m×3mのタープなど、区画より大きい）
- [ ] キッチンカーのメニューは聞いていない（必要なら追加）
- [ ] 公開前: 「回答を受け付ける」をオン、分岐をプレビューで全区分確認

## 文面の置き場所
- 募集要項に足す「出店情報のご提出」の章（アリーナ・飲食・キッチンカー版）、提出書類の章（キッチンカー版）、メール文は、このチャットで作成した
